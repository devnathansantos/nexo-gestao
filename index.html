Instalar no iPhone

No Safari, toque em Compartilhar e depois “Adicionar à Tela de Início”. Para os dados ficarem mais seguros, faça backup e guarde o arquivo em outro local.

NEXO V4 funciona sem servidor e sem mensalidade. Os dados ficam neste navegador. Se limpar os dados do Safari, trocar de aparelho ou usar outro navegador, os registros não acompanham você automaticamente.
